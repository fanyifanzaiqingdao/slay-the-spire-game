# Ascendant 玩法机制文档（当前实现版）

> 本文档基于当前代码实现整理，描述“玩家实际玩到的规则”，用于策划对齐、测试用例编写和新成员快速上手。

## 1. 核心定位与目标循环

- 游戏类型：单人回合制卡牌 + Roguelike 地图推进 + 语言学习问答。
- 核心理念：**战斗就是学习**，每次出牌都要回答题目，答题结果直接决定战斗效果。
- 一局流程：
  1. 主菜单开始新局（可选 Blessing+Curse 修正词）。
  2. 地图选点推进（战斗/精英/休息/商人/事件/Boss）。
  3. 战斗后领取战利品（金币、药水、卡牌草案）。
  4. 继续爬塔，直至失败或阶段胜利进入结算。

## 2. 地图与房间机制

## 2.1 地图生成

- 地图为 15 行内容层 + 顶部 Boss 节点，7 列宽。
- 起始会生成多条路径，支持分叉与汇合。
- 节点类型权重大致为：
  - 战斗 45
  - 事件 22
  - 商人 12（受约束）
  - 休息 12（受约束）
  - 精英 16（仅较高层出现）
- 约束规则：
  - 同一路径避免连续出现休息/商人/精英。
  - 最后一层固定休息节点，再连到 Boss。
- 进入节点后：
  - 当前行其他可选点失效（避免同层多选）。
  - 只解锁当前点可到达的下一层节点。

## 2.2 房间类型

- `Combat/Elite/Boss`：进入战斗。
- `Rest`（休息点）：
  - 休息回血：恢复最大生命 25%（受诅咒和 Mastery 规则影响）。
  - 复习：用于学习向收益（当前实现为流程节点）。
  - Vault：若有仓库遗物，可在此打开遗物仓库进行切换。
- `Merchant`（商人）：
  - 出售 3 张卡（常见/非凡/稀有各 1 张）。
  - 支持花钱移除牌组中 1 张卡。
  - 价格受诅咒（税）和部分遗物影响。
- `Event`（事件）：
  - 二选一/多选一事件分支，按选项给奖励或惩罚（金币、回血、扣血等）。

## 3. 战斗状态机与回合顺序

战斗严格遵循阶段机：

1. `PLAYER_DRAW`
   - 解锁上回合被锁定的卡。
   - 抽牌（默认 5 张，受 Debuff/修正词影响）。
   - 设置本回合能量（默认 3，受 Debuff/修正词影响）。
2. `PLAYER_TURN`
   - 玩家打牌 -> 触发题目。
   - 正确：结算卡牌效果。
   - 错误：卡牌锁定到回合结束，并给敌人错误增益。
3. `ENEMY_TURN`
   - 敌人按 intent_pattern 顺序执行整套动作（可多段）。
   - 行动结束后推进 intentIndex。
   - 清空敌方“错误增益缓存”，tick 玩家 Debuff。
4. `FIGHT_END`
   - 胜利进入战利品/草案，失败进结算。

## 4. 出牌与答题机制（学习战斗耦合）

## 4.1 出牌前检查

- 能量是否足够。
- 卡是否被锁定（lockedCards）。
- 卡类型是否被沉默（silence）。
- 是否触发 `type_lock`（不能连续打同类型卡）。

## 4.2 题目抽样

- 按卡牌类型与标签筛题。
- 按楼层筛题池（floor tier 过滤）。
- **同一场战斗内题目不重复**（fightQuestionPoolUsed）。
- 题池耗尽会局部重置并警告日志（极端长战斗兜底）。
- 间隔重复（Spaced Repetition）：
  - 错得多的问题权重更高。
  - 连续答对的问题权重下降。
  - 让你更常看到薄弱点。

## 4.3 题目作答与反馈

- 支持计时（normal/fast/relaxed/off）。
- 可使用提示（通常消耗 1 能量，部分 Blessing 免费）。
- 可受药水影响（2 选 1、自动正确、冻结计时等）。
- 答对：
  - 记正确统计、更新墓园熟练度、可能触发连锁和额外效果。
  - 扣能量并把卡移入弃牌。
- 答错/超时：
  - 记错题统计。
  - 该卡本回合锁定不可再用。
  - 连锁中断。
  - 给敌人叠加对应类型的“错误增益”。

## 5. 卡牌、能量与连锁（Chain）

- 卡牌有类型（词汇/语法/阅读等）、稀有度、能量消耗、效果。
- 常见效果：伤害、格挡、治疗、抽牌、连锁加成、弃牌抽牌、自我放逐换能量等。
- 连锁机制：
  - 连续正确会叠连锁，提升倍率。
  - 答错即断连。
  - 某些遗物可让不同类型也可连锁。

## 6. 敌人与意图系统

- 敌人具备：
  - base_attack
  - intent_pattern（按回合循环的动作列表）
  - wrong_answer_buffs（按卡类型定义的错误惩罚增益）
- 动作类型覆盖：
  - 直接攻击（普通/重击/连击）
  - Debuff（silence/drain/fog/bind/confusion）
  - 自身增益（护甲、回复、狂怒、聚焦抗性）
- 部分机制：
  - Fury 到阈值后下一击翻倍并重置。
  - 攻击先吃玩家格挡，再扣血。
  - `last_stand` 祝福可在致命伤时保命一次（1 HP）。

## 7. 资源与成长系统

## 7.1 基础资源

- HP / MaxHP
- 能量 / 最大能量
- 金币
- 牌组、手牌、弃牌、放逐

## 7.2 药水系统（最多 3 格）

- 稀有度：common / uncommon / rare。
- 获取：战斗掉落、商店（视实现）。
- 用途示例：
  - 即时回血、加能量、加格挡
  - 激活连锁、冻结计时、清 Debuff
  - 下一张牌触发两次
  - 自动判定正确

## 7.3 遗物系统（装备槽 + 仓库）

- 装备槽上限 5，超出时进入替换流程或仓库存储。
- 分级：starter/common/uncommon/rare/pantheon。
- 触发面覆盖：
  - 开场护甲/金币
  - 连锁强化
  - 错误惩罚减免
  - 特定类型卡牌强化
  - 特定条件达成触发收益

## 7.4 修正词（Blessing + Curse）

- 开局可从 3 组中选择 1 组，或跳过。
- 每组为“一祝福 + 一诅咒”绑定。
- 典型组合影响：
  - 更高伤害 vs 更低初始血量
  - 额外抽牌 vs 手牌混乱
  - 免费提示 vs 草案信息受限
  - 更多能量 vs 无法获得格挡

## 7.5 Mastery（熟练度规则）

- Mastery 规则是累计生效的难度层（1~10）。
- 示例：
  - 去罗马音
  - 选项变少
  - 计时更短
  - 错误惩罚加倍
  - 休息点禁疗
  - 商人无翻译
  - 草案缩小

## 7.6 墓园（Mistake Graveyard）

- 持久记录错题与熟练度（correct streak）。
- 连续正确达到阈值可标记 mastered。
- 既用于复盘显示，也用于题目加权（强化薄弱点训练）。

## 7.7 Pantheon 元进度

- 跨局累计 XP：
  - 每次正确 +2 XP
  - 每层 +20 XP
  - 胜利额外 +100 XP
- 提升 Pantheon 等级可解锁卡牌/遗物等长期奖励。

## 8. 战斗后奖励与局外结算

## 8.1 战利品流程

- 通常包含：
  - 金币
  - 可能掉落药水
  - 卡牌草案机会（openDraft）
- 玩家可逐项领取，完成后回地图。

## 8.2 卡牌草案（Draft）

- 默认给 3 选 1（受 Mastery 规则影响可能变少）。
- 稀有池受本场准确率影响（高准确率可进更高稀有池）。
- Boss 奖励可指定稀有度池。

## 8.3 结算页（PostRunSummary）

- 展示：
  - 学到了什么（词汇/语法条目）
  - 哪些点容易错（top missed）
  - 本局模式分析建议
- 同时写入：
  - 墓园持久数据
  - Progress run 统计
  - Pantheon XP 累计

## 9. 当前设计重点（平衡意图）

- 答错不是“纯惩罚”，而是“战术后果”：
  - 不耗能，但锁卡 + 给敌方机会。
- 玩家策略重心：
  - 当前回合先打哪类卡
  - 要不要为提示付能量
  - 何时断连、何时保命
  - 地图路线与商店/休息点权衡
- 学习策略重心：
  - 通过墓园和加权抽题反复攻克弱项
  - 在压力场景中强化提取速度和准确率

## 10. 测试关注清单（供 QA/自测）

- 地图层级推进是否只能走已解锁路径。
- 同战斗内是否绝不重复题目（正常池）。
- 错误后卡牌是否锁定至回合结束并正确解锁。
- 敌人是否只在敌方回合结算动作链。
- Debuff 是否按回合递减并到期移除。
- 战后奖励领取与草案流程是否能完整回到地图。
- 结算后墓园与 Pantheon 数据是否正确累加持久化。
