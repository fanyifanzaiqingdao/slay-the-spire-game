# Ascendant 玩法机制文档（战斗版）

> 本版本仅保留战斗与Roguelike推进机制，不包含学习/答题相关系统。

## 1. 核心定位与目标循环

- 游戏类型：单人回合制卡牌 + Roguelike 地图推进。
- 核心目标：通过构筑与资源管理击败各层敌人与Boss。
- 一局流程：
  1. 开始新局（可选 Blessing+Curse 修正词）。
  2. 地图选点推进（战斗/精英/休息/商人/事件/Boss）。
  3. 战斗后领取战利品（金币、药水、卡牌草案）。
  4. 继续爬塔，直至失败或通关阶段Boss。

## 2. 地图与房间机制

### 2.1 地图生成

- 地图为 15 行内容层 + 顶部 Boss 节点，7 列宽。
- 起始多路径，支持分叉汇合。
- 节点权重大致为：
  - 战斗 45
  - 事件 22
  - 商人 12
  - 休息 12
  - 精英 16
- 约束规则：
  - 同路径避免连续休息/商人/精英。
  - 最后一层固定休息，再连接 Boss。
- 行进规则：
  - 每层只可选择一个节点。
  - 仅解锁当前节点可达的下一层节点。

### 2.2 房间类型

- `Combat/Elite/Boss`：进入战斗。
- `Rest`：回血（恢复最大生命25%）或进入 Vault 调整遗物配置。
- `Merchant`：买卡、移除卡、消耗金币做构筑优化。
- `Event`：事件分支给战斗向收益或惩罚（金币、生命、资源等）。

## 3. 战斗状态机与回合顺序

战斗遵循固定阶段机：

1. `PLAYER_DRAW`
   - 抽牌（默认 5 张，受Debuff/修正词影响）。
   - 设置本回合能量（默认 3，受Debuff/修正词影响）。
2. `PLAYER_TURN`
   - 玩家打牌并结算卡牌效果。
   - **每张卡牌仅根据“当前能量是否足够”判断是否可打出。**
3. `ENEMY_TURN`
   - 敌人按 `intent_pattern` 顺序执行动作链（可多段）。
   - 行动后推进 `intentIndex`，并处理Debuff回合结算。
4. `FIGHT_END`
   - 胜利进入战利品与草案，失败进入结算页。

## 4. 出牌规则（纯能量判定）

- 出牌前只检查：
  - `当前能量 >= 卡牌能量消耗`
- 能量充足：
  - 允许打出，立即结算卡牌效果。
  - 扣除对应能量。
  - 卡牌从手牌进入弃牌（或按效果进入放逐等区域）。
- 能量不足：
  - 卡牌不可打出。

## 5. 卡牌与效果系统

- 卡牌属性：
  - 类型
  - 稀有度
  - 能量消耗
  - 效果描述
- 常见效果：
  - 伤害
  - 格挡
  - 治疗
  - 抽牌
  - 弃牌抽牌
  - 自我放逐换能量
  - 连锁/倍率增益（若启用）

## 6. 敌人与意图系统

- 敌人核心字段：
  - `base_attack`
  - `intent_pattern`（按回合循环的动作列表）
- 敌方动作类型：
  - 直接攻击（普通/重击/连击）
  - Debuff（沉默、减能、减抽牌、混乱等）
  - 自身增益（护甲、回血、狂怒、聚焦）
- 结算原则：
  - 攻击先消耗玩家格挡，再扣生命。
  - 部分Boss/敌人动作存在阶段触发与倍率变化。

## 7. 资源与构筑系统

### 7.1 基础资源

- HP / MaxHP
- 能量 / 最大能量
- 金币
- 牌组、手牌、弃牌、放逐

### 7.2 药水系统（最多3格）

- 稀有度：common / uncommon / rare。
- 获取：战斗掉落、商店。
- 战斗用途示例：
  - 回血、加能量、加格挡
  - 清Debuff
  - 下一张牌触发两次
  - 其他瞬时战斗效果

### 7.3 遗物系统（装备槽 + 仓库）

- 装备槽上限5，超出时在装备与仓库间替换。
- 分级：starter/common/uncommon/rare/pantheon。
- 触发覆盖：
  - 开场护甲/金币
  - 连锁强化
  - 特定卡牌类型强化
  - 条件达成触发奖励

### 7.4 修正词（Blessing + Curse）

- 开局可从3组中选择1组，或跳过。
- 每组为“一祝福 + 一诅咒”绑定。
- 影响方向包括：
  - 伤害/生存/抽牌/能量
  - 商店成本
  - 防御限制等

### 7.5 Mastery（战斗难度规则）

- Mastery为累计生效难度层（1~10）。
- 示例方向：
  - 计时缩短
  - 敌方惩罚增强
  - 休息点限制
  - 商店限制
  - 草案规模缩小

### 7.6 Pantheon 元进度

- 跨局累积XP并提升等级。
- 解锁新卡牌/遗物等奖励，影响后续局内构筑空间。

## 8. 战斗后奖励与结算

### 8.1 战利品流程

- 通常包含：
  - 金币
  - 药水掉落
  - 卡牌草案机会
- 玩家可逐项领取，完成后回地图。

### 8.2 卡牌草案（Draft）

- 默认 3 选 1（可能受难度规则缩减）。
- 稀有池可随战斗表现与事件奖励变化。
- Boss奖励可指定更高稀有度池。

### 8.3 结算页

- 展示本局战斗表现、推进层数、胜负结果与成长信息。
- 写入进度数据用于长期成长统计。

## 9. 战斗设计重点

- 资源管理优先级：
  - 能量分配
  - 手牌节奏
  - 防御与进攻窗口
- 路线决策优先级：
  - 精英风险 vs 奖励
  - 休息/商人节点收益
  - Boss前资源准备
- 构筑决策优先级：
  - 去除低效卡
  - 补齐关键功能卡
  - 利用遗物与药水形成组合强度

## 10. 测试关注清单（供 QA/自测）

- 卡牌可打出判定是否仅由能量控制。
- 能量扣除、弃牌/放逐流转是否正确。
- 敌人是否仅在敌方回合执行动作链。
- Debuff是否按回合递减并正确移除。
- 战后奖励领取与草案流程是否能回到地图。
- 结算与Pantheon进度是否正确持久化。
